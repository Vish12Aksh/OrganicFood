Modern React + Vite e‑commerce app for organic food with user/admin roles

Tech stack: React 18, Vite, Material Tailwind, Redux Toolkit, React Router, Tailwind CSS, Firebase

User features: signup/auth, browse products, cart, product details, dashboard

Admin features: dashboard, product/category CRUD, role‑protected routes

UX/UI: responsive layout, scroll‑to‑top, toast notifications

Security: role‑based route protection, Firebase auth
